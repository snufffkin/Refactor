# Анализ контента карточек с помощью OpenAI

Этот скрипт добавляет в таблицу `cards_content` два новых поля:
- `card_description` - краткое описание карточки по её контенту
- `card_complaints` - суммаризация сути жалоб на карточку от пользователей

## Настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта и добавьте ваш API ключ OpenAI:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

Также убедитесь, что настроены переменные для подключения к базе данных:

```env
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=your_db_host
DB_PORT=your_db_port
DB_NAME=your_db_name
```

### 3. Проверка миграции базы данных

Поля `card_description` и `card_complaints` должны быть добавлены в таблицу `cards_content`. Если они отсутствуют, выполните миграцию:

```sql
ALTER TABLE cards_content 
ADD COLUMN card_description TEXT,
ADD COLUMN card_complaints TEXT;
```

## Описание работы скрипта

### Фильтрация карточек

Скрипт обрабатывает только карточки из программ, где `program_refactor_status = TRUE` в таблице `program_ids`.

### Анализ контента

Для создания описания карточки скрипт использует:

1. **Текстовые блоки** (`text_blocks`) - извлекает текст из JSON структуры
2. **Медиа-контент** (`media`) - подсчитывает изображения, видео, аудио, ссылки
3. **Интерактивные элементы** (`interactives`) - использует предопределенные описания для каждого типа:

   - `inline`: Блоки для ввода текста или выбора из вариантов
   - `choice`: Выбор одного или нескольких вариантов ответа
   - `dragimage`: Перетаскивание блоков на соответствующие поля
   - `chooseimage`: Выбор области на картинке
   - `macaroni`: Соединение элементов списков линиями
   - `polylines`: Соединение любых элементов на изображении
   - `diskurl`: Поле для ссылки на Яндекс Диск
   - `coloring`: Раскраска определенных полей цветами

### Анализ жалоб

Для суммаризации жалоб скрипт использует поле `complaints_text` из таблицы `cards_metrics`.

### Формат запроса к OpenAI

Скрипт делает один запрос к GPT-3.5-turbo для каждой карточки, запрашивая:
1. Краткое описание карточки (2-3 предложения)
2. Суммаризацию жалоб (если есть)

Ответ ожидается в JSON формате:
```json
{
    "card_description": "краткое описание карточки",
    "card_complaints": "суть жалоб или null если жалоб нет"
}
```

## Логирование

Скрипт ведет подробные логи:
- В файл `analyze_cards_content.log`
- В консоль

Логи включают:
- Прогресс обработки карточек
- Успешные обновления
- Ошибки подключения к API или базе данных
- Статистику по завершении

## Ограничения и особенности

- **Rate limiting**: Скрипт делает паузу 1 секунда между запросами к OpenAI API
- **Повторная обработка**: Скрипт пропускает карточки, у которых уже заполнены поля `card_description` и `card_complaints`
- **Лимит карточек**: По умолчанию обрабатывается не более 100 карточек за раз
- **Обработка ошибок**: При ошибке анализа конкретной карточки скрипт продолжает работу

## Стоимость

Примерная стоимость анализа одной карточки с помощью GPT-3.5-turbo составляет $0.001-0.003, в зависимости от объема контента.

## Устранение проблем

### Ошибка "OPENAI_API_KEY не найден"
Убедитесь, что файл `.env` создан и содержит корректный API ключ.

### Ошибки подключения к базе данных
Проверьте переменные окружения для подключения к БД в файле `.env`.

### Ошибки JSON парсинга
Иногда OpenAI может вернуть ответ не в ожидаемом JSON формате. Скрипт пытается обработать такие случаи, но при частых ошибках может потребоваться корректировка промпта.

### Rate limit ошибки OpenAI
Увеличьте паузу между запросами в строке `time.sleep(1)` на большее значение.
